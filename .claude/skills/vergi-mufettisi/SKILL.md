# Claude Code yönlendiricisi

1. `skills/vergi-mufettisi/SKILL.md` dosyasını baştan sona oku ve kanonik talimat olarak uygula.
2. Bu yeteneğin yönlendirdiği ilgili referansları oku; genel hesaplama ve mükellef menfaati kuralları için `skills/muhasebecim/SKILL.md` ile birlikte çalış.
3. `CLAUDE.md` içindeki hassas veri sınırını uygula.
4. Kamu yetkisi, resmî inceleme, tarhiyat veya kesin hukuki sonuç iddiasında bulunma.
